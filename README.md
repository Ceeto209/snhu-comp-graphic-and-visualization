# CS-330: Computational Graphics and Visualization

## Project Overview

For my CS-330 final project, I developed an interactive 3D scene using C++ and OpenGL. The scene features a computer monitor displaying a binary-code texture, a wooden desk surface, and a lamp that provides lighting. The project demonstrates my understanding of 3D transformations, textures, lighting, and camera navigation.

## How Do I Approach Designing Software?

My approach to designing software starts with breaking a larger problem into smaller, manageable components. For this project, I began by identifying the objects needed to recreate my chosen scene and determining which basic 3D shapes could represent them. Building the computer monitor helped me better understand how to combine and transform shapes into more complex objects. I also learned how important lighting, textures, and positioning are when creating a realistic scene.

I followed an incremental design process, starting with the basic objects and gradually adding camera movement, textures, and lighting. This approach allowed me to focus on individual features before combining them. I can apply this same process to future software projects by planning components, implementing them individually, and refining the overall design through testing.

## How Do I Approach Developing Programs?

Throughout this course, I developed a better understanding of working with C++ and OpenGL to create visual applications. One strategy I found useful was making small changes and running the program frequently to verify the results. This was especially helpful when adjusting object positions, applying textures, and configuring lighting.

Iteration played an important role in completing my 3D scene. For example, I adjusted the monitor's appearance, refined the lamp's proportions, and experimented with lighting values until the objects were clearly visible. Each milestone introduced new functionality that built on the previous work. By the end of the course, I had become more comfortable troubleshooting graphical issues and understanding how different parts of the rendering process work together.

## How Can Computer Science Help Me Reach My Goals?

Computer science continues to help me develop the technical and problem-solving skills needed for my goal of becoming a software developer. Although my primary interests are backend and full-stack development, this course introduced me to another important area of programming.

Working with computational graphics strengthened my understanding of coordinate systems, mathematical transformations, and how software interacts with hardware to produce visual results. These concepts can also be useful when working with interactive applications, data visualizations, and user interfaces.

Professionally, this experience reinforced the importance of testing, debugging, and incremental development. These are skills I can apply to future programming projects regardless of whether they involve graphics, web development, or software automation.
